# 🌿 ระบบแจ้งจัดเก็บขยะไร้บ้าน (Homeless Waste Collection Request System)

ระบบเว็บแอปพลิเคชัน Full-Stack สำหรับให้ประชาชนแจ้งจุดที่มีขยะต้องการให้หน่วยงานเข้าไปจัดเก็บ พร้อมระบบบริหารจัดการ มอบหมายงาน ติดตามสถานะแบบเรียลไทม์ และระบบนำทาง GPS สำหรับเจ้าหน้าที่ภาคสนาม

---

## 🚀 คุณสมบัติเด่นของระบบ (Core Features)

### 1. 👥 สำหรับประชาชน (Public Portal - ไม่ต้อง Login)
- **แจ้งจัดเก็บขยะ:** ป้อนชื่อ, เบอร์โทร, รายละเอียดสถานที่ พร้อมอัปโหลดรูปภาพก่อนจัดเก็บ (Before Photo)
- **เลือกประเภทขยะได้หลายประเภทใน 1 ครั้ง (Multi-select Waste Types):** สามารถเลือกประเภทขยะที่พบได้มากกว่า 1 ประเภท พร้อมระบุน้ำหนักประมาณการ (กก.) ของแต่ละประเภทแยกกันได้อย่างอิสระ
- **แสดงรูปภาพภาพประกอบประเภทขยะ (Visual Waste Category Illustrations):** การ์ดแต่ละประเภทแสดงรูปภาพ 3D Vector ชัดเจน สวยงาม ช่วยให้ประชาชนจำแนกประเภทขยะ (ขยะทั่วไป, ขยะเปียก, ขยะรีไซเคิล, ขยะอันตราย, ขยะชิ้นใหญ่, E-Waste) ได้อย่างถูกต้อง
- **คำนวณน้ำหนักรวมแบบเรียลไทม์ (Live Weight Calculation):** สรุปจำนวนประเภทที่เลือกและคำนวณน้ำหนักรวมทั้งหมดให้อัตโนมัติทันที
- **แผนที่พิกัดความแม่นยำสูงและค้นหาสถานที่ (High-Precision Map & Smart Geocoding):**
  - **ช่องค้นหาอัจฉริยะ (Smart Place & Street Search):** พิมพ์ค้นหาชื่อ ซอย, ถนน, ชุมชน, หรือสถานที่สำคัญ (เช่น "ซอยติวานนท์ 24", "ตลาดนนท์", "วัดบัวขวัญ") แผนที่จะซูมและปักหมุดตรงจุดทันที
  - **ปุ่มลัดโซนเทศบาลนครนนทบุรี (Quick Landmark Chips):** คลิก 1 ครั้งเพื่อบินไปยังย่านหลัก (ท่าน้ำนนท์, ศูนย์ราชการ, แคราย, เดอะมอลล์งามวงศ์วาน, ถ.รัตนาธิเบศร์)
  - **ระบบตรวจสอบความแม่นยำ GPS (Accuracy Circle & Feedback):** แสดงวงรัศมีความคลาดเคลื่อนของ GPS และแจ้งเตือนหากสัญญาณคลาดเคลื่อนพร้อมแนะนำให้ลากหมุด
  - **ดึงที่อยู่อัตโนมัติ (Auto Reverse Geocoding):** แปลงพิกัดเป็นชื่อถนน แขวง/ตำบล เขต/อำเภอ และ จ.นนทบุรี ให้อัตโนมัติทันที

- **ระบบเลขที่รายการอัตโนมัติ:** สร้างรหัสเฉพาะ `WB-YYYY-XXXXXX` (เช่น `WB-2026-000001`) พร้อมปุ่มคัดลอก
- **ติดตามสถานะงาน (Tracking):** ค้นหาด้วยเลขที่รายการหรือเบอร์โทรศัพท์ เพื่อดูไทม์ไลน์สถานะงาน รูปภาพ Before/After แสดงแยกประเภทขยะและน้ำหนักแต่ละประเภท




### 2. 🛡️ สำหรับผู้ดูแลระบบ (Admin Portal)
- **Dashboard สรุปภาพรวม:** Card แสดงจำนวนงานแยกตามสถานะ, น้ำหนักประมาณการรวม, น้ำหนักจริงรวมที่จัดเก็บได้
- **กราฟสถิติ:** กราฟแนวโน้มรายเดือน และสัดส่วนประเภทขยะด้วย Chart.js
- **แผนที่รวมจุดแจ้งขยะ (Live Map):** แสดง Marker สีตามสถานะงาน สามารถคลิกเพื่อดูรายละเอียดและสั่งการได้ทันที
- **การจัดการรายการขยะ:** ระบบค้นหาและตัวกรองละเอียด (สถานะ, ประเภทขยะ, ช่วงวันที่)
- **การจัดการสถานะและบันทึกผลงานโดยตรง:** ปรับสถานะงาน, ชั่งน้ำหนักจริง (กก.), อัปโหลดรูปภาพหลังจัดเก็บ (After Photo) และบันทึกหมายเหตุจบงานได้ในที่เดียว
- **การจัดการประเภทขยะ (Waste Types Management):** เพิ่ม, แก้ไข, ปิด/เปิดใช้งาน, ลบประเภทขยะ พร้อมดูสถิติจำนวนรายการและน้ำหนักรวมของแต่ละประเภท
- **ระบบแจ้งเตือนภายในเว็บไซต์ (In-App Notification):** แจ้งเตือนเมื่อมีรายการแจ้งใหม่ หรืองานเสร็จสิ้น พร้อมตัวเลข Unread Badge บนไอคอนกระดิ่ง
- **ส่งออกรายงาน:** Export ข้อมูลเป็น Excel / CSV ตามช่วงเวลาและตัวกรองที่เลือก


### 3. 👷 สำหรับเจ้าหน้าที่เก็บขยะ (Staff Mobile Portal)
- **ออกแบบ Mobile-First:** ใช้งานสะดวกรวดเร็วบนโทรศัพท์มือถือขณะลงพื้นที่
- **งานของฉัน (My Assigned Tasks):** แสดงรายการงานที่ตนเองได้รับมอบหมาย
- **ระบบนำทาง GPS:** มีปุ่มกดเปิด Google Maps นำทางไปยังจุดทิ้งขยะได้ทันที และปุ่มโทรหาผู้แจ้ง
- **อัปเดตสถานะงาน 3 ขั้น:** `รับงานแล้ว` ➔ `กำลังเดินทาง` ➔ `กำลังดำเนินการ`
- **บันทึกผลและปิดงาน:** ป้อนน้ำหนักขยะที่จัดเก็บได้จริง (กก.), อัปโหลดรูปภาพหลังจัดเก็บ (After Photo), และบันทึกหมายเหตุเพื่อเปลี่ยนสถานะเป็น `จัดเก็บเรียบร้อยแล้ว`

## 🗄️ โครงสร้างฐานข้อมูล (Database: `behn_abandoned_waste`)

| ตาราง (Table) | หน้าที่ |
| :--- | :--- |
| `users` | บัญชีผู้ใช้งานระบบ (Admin / Staff) เข้ารหัสผ่านด้วย Bcrypt |
| `waste_types` | หมวดหมู่ขยะไร้บ้าน 12 หมวดหลัก (ตามเทศบาลนครนนทบุรี) |
| `collection_schedules` | รอบปฏิทินจัดเก็บขยะไร้บ้านและขยะชิ้นใหญ่ประจำเดือน |
| `waste_reports` | ตารางหลักเก็บรายการแจ้งขยะ พิกัด Lat/Lng น้ำหนักประมาณการ และน้ำหนักจริง |
| `waste_report_items` | รายการย่อยประเภทขยะและน้ำหนักแต่ละรายการในคำร้อง |
| `waste_report_images` | รูปภาพประกอบการดำเนินงานแยกประเภท `before` และ `after` |
| `assignments` | ประวัติการมอบหมายงานระหว่าง Admin และ Staff |
| `status_histories` | ประวัติการเปลี่ยนสถานะงานทุกขั้นตอน (State Transitions & Timeline) |
| `notifications` | การแจ้งเตือน In-App ภายในเว็บไซต์ (มี Badge แจ้งเตือน) |
| `activity_logs` | บันทึกประวัติการกระทำสำคัญในระบบเพื่อความปลอดภัย |

## 🛠️ วิธีการติดตั้งและเริ่มใช้งาน

### วิธีที่ 1: รันบน XAMPP (Local Development)
1. เปิด **XAMPP Control Panel** และ Start **Apache** กับ **MySQL**
2. ฐานข้อมูลจะเชื่อมต่อไปยัง `behn_abandoned_waste` บน `localhost:3306` (User: `root`, รหัสผ่านว่าง)
3. รัน Migration และ Seeder ข้อมูลตัวอย่าง (ถ้าต้องการรีเซ็ตข้อมูล):
   ```bash
   php database/migrate.php
   ```
4. เข้าใช้งานผ่านเบราว์เซอร์:
   - **หน้าเว็บประชาชน:** `http://localhost/ขยะไร้บ้าน/public/`
   - **หน้าเข้าสู่ระบบ:** `http://localhost/ขยะไร้บ้าน/public/login`
   - **หน้าติดตามสถานะ:** `http://localhost/ขยะไร้บ้าน/public/track`

---

### วิธีที่ 2: รันผ่าน Docker & Docker Compose
ระบบมีไฟล์คอนฟิก `Dockerfile` และ `docker-compose.yml` สำหรับ Multi-container (PHP-FPM, Nginx, MySQL, Redis) พร้อมใช้งาน:

```bash
# สั่ง Build และ Start Container ในโหมด Background
docker compose up -d --build

# ตรวจสอบสถานะ Container
docker compose ps

# รัน Migration ภายใน Container
docker compose exec app php database/migrate.php

# ดู Logs
docker compose logs -f

# หยุดการทำงาน
docker compose down
```
เข้าใช้งานผ่าน URL: `http://localhost:8080`
