# Obsidian

> **Category:** `tool`  
> **Primary Role:** The Interactive IDE for Personal Knowledge Bases

---

## 📋 Profile & Description
**Obsidian** is a local-first, extensible markdown knowledge management application based on plain text files. In the [[llm-wiki]] ecosystem, Obsidian serves as the user-facing IDE (interactive visual layer), while the LLM acts as the backend programmer.

---

## 🎯 Key Capabilities in LLM Wiki Workflow
1. **Interactive Graph View:** Visualizes associative trails, concept clusters, and orphan nodes.
2. **Dataview Plugin:** Executes SQL/DQL queries over YAML frontmatter across `wiki/`.
3. **Obsidian Web Clipper:** Captures web sources into `raw/` with automatic local asset downloads.
4. **Marp Presentation Plugin:** Renders markdown slide decks generated in `wiki/queries/`.
