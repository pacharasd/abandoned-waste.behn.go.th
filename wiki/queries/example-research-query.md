# Query Record: Compounding vs Ephemeral Knowledge Architectures

> **Prompt / Question:** *"Why does the LLM Wiki pattern outperform standard RAG for long-term personal research?"*
> **Resolved Date:** 2026-08-31

---

## 💡 Synthesized Answer
The LLM Wiki pattern outperforms standard RAG because it shifts the cognitive synthesis burden from **Query Time** (where context is lost between sessions) to **Ingest Time** (where knowledge is actively compiled and cross-referenced).

### 3 Key Pillars:
1. **Compilation over Re-derivation:** The wiki contains pre-digested [[concepts/llm-wiki|LLM Wiki]] and [[concepts/persistent-compounding-knowledge|Compounding Knowledge]] notes that already have cross-references to [[entities/obsidian|Obsidian]] and [[entities/vannevar-bush-memex|Memex]].
2. **Explicit Contradiction Tracking:** When sources disagree, the wiki documents the tension rather than hallucinating a blended average.
3. **Auditability & Visual Exploration:** The user can visually inspect relationships in Obsidian Graph View and query metadata via Dataview.
